## 1. 后端接口清单

### 1.1 基础约定

| 项 | 约定 |
| --- | --- |
| 服务地址 | 本地开发 `http://localhost:8000` |
| 业务前缀 | 除 `/health` 和 `/uploads/*` 外，所有接口都在 `/api/v1` 下 |
| 编码 | UTF-8，JSON 一律 `Content-Type: application/json` |
| 统一返回 | `{ "code": 0, "message": "ok", "data": { ... } }`，`code == 0` 表示成功 |
| 鉴权 | `Authorization: Bearer <token>`，token 由登录接口签发（JWT） |
| 响应追踪 | 每个响应带 `X-Trace-Id` 头，报错时把它一起发给后端同学 |

**统一错误码**

| code | 含义 |
| --- | --- |
| 40001 | 参数校验失败 |
| 40002 | 上传文件缺失或类型不合法 |
| 40003 | 上传文件超出体积上限 |
| 40101 | 未提供鉴权 Token |
| 40102 | Token 无效或已过期 |
| 40301 | 权限不足 |
| 50000 | 未预期的服务端异常 |
| 50001 | 语音识别服务不可用 |
| 50002 | 语音合成服务不可用 |

> 例外：`/api/v1/chat/stream` 的错误体是 `{ "error": "..." }`；`/api/v1/analytics/log` 参数错误码是 `10001`；知识库模块的 `code` 直接复用 HTTP 状态码。对接时按接口实际情况处理。

**鉴权说明（游客端）**

- 景区导览、问答、语音、失物招领这些游客接口**都不强制登录**，不带 token 也能调。
- 需要 token 的只有：`GET /api/v1/auth/me`，以及后台管理类接口（一期不做）。
- 登录成功后把 token 存 DataStore，之后在 OkHttp 拦截器里统一加 `Authorization` 头；token 过期（40101 / 40102）就清本地登录态回登录页。

### 1.2 游客端 7 个页面用到的接口

#### 登录页

| 方法 | 路径 | 入参 | 返回 `data` | 鉴权 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/auth/login` | `{ username, password }` | `{ user: {...}, token }` | 否 |
| POST | `/api/v1/auth/register` | `{ username, password, nickname? }` | `{ id }`（HTTP 201） | 否 |
| GET | `/api/v1/auth/me` | — | 当前用户对象 | **是** |

- 密码至少 6 位；用户名重复返回 409。
- `user` 对象含 `id / username / nickname / role` 等字段，`role` 为 `user`。
- **注意（已知限制）**：用户库是 SQLite，文件落在系统临时目录（`os.tmpdir()/whoisthe4th-auth.db`），**后端一重启账号就全丢**。联调前先注册一个账号；每次演示前统一重新注册一遍。详见 3.1 第 8 条。

#### 首页

| 方法 | 路径 | 入参 | 返回 `data` | 鉴权 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/home` | — | 聚合对象：banners、quickEntries、hotPois、recommendedRoutes、运营统计 | 否 |

#### 景点列表页

| 方法 | 路径 | 入参 | 返回 `data` | 鉴权 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/poi` | `category?`、`all=1?`（`all=1` 含下架） | 景点数组（最多 200 条，无分页） | 否 |

景点对象关键字段：`id`、`name`、`category`、`description`、`location`、`longitude`、`latitude`、`status`。

#### 景点详情页

| 方法 | 路径 | 入参 | 返回 `data` | 鉴权 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/poi/{id}` | — | 单条景点完整记录 | 否 |

- `id` 非法返回 400 / `40001`；不存在返回 404 / `40401`。

#### AI 问答页（含语音）

| 方法 | 路径 | 入参 | 返回 | 鉴权 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/chat/stream` | `{ message }` 或 `{ messages: [{role, content}] }` | **SSE 流** | 否 |
| POST | `/api/v1/chat/stop` | `{ sessionId, reason }` | `{ code, message, data }` | 否（规划态） |
| POST | `/api/v1/asr-tts/asr` | `multipart/form-data`，字段名固定为 **`audio`** | `{ text }` | 否 |
| GET | `/api/v1/tts/stream` | query：`text`（≤ 500 字）、`lastSeq`（续传用，默认 0） | **SSE 流（音频分片）** | 否 |
| POST | `/api/v1/analytics/log` | `{ userId, message, response?, scenicSpot? }` | `{ id, sentimentScore, sentimentLabel }` | 否 |

**SSE 事件（`POST /api/v1/chat/stream`）**

| event | data | 说明 |
| --- | --- | --- |
| `token` | `{ "content": "增量文本" }` | 逐段返回，客户端自行拼接；带自增 `id` |
| `done` | `{ "fullContent": "完整回答" }` | 正常结束 |
| `error` | `{ "message": "错误原因" }` | 异常结束，**之后还会补发一个空的 `done`（`{}`）** |

- 心跳是注释行（`:` 开头，每 25 秒），客户端必须忽略。
- 响应头会带 `X-Session-Id`，停止对话时回传给 `/chat/stop`。

**SSE 事件（`GET /api/v1/tts/stream`）**

| event | data | 说明 |
| --- | --- | --- |
| `meta` | `{ streamId, text, provider, sampleRate, ... }` | 流开始，先于音频分片 |
| `audio` | `{ seq, chunk: "<base64>", byteLength }` | 音频分片，`chunk` 是 Base64 编码的音频字节；`id` 字段等于 `seq` |
| `done` | `{ streamId, totalChunks, provider }` | 合成结束 |
| `error` | `{ code: 50002, message }` | 合成失败 |

- 断线续传：重连时带上 `lastSeq=上次收到的最大 seq`，服务端会跳过 ≤ 该值的分片。
- 文本上限 500 字符，长回答要自己按句号切段多次请求。

#### 失物招领页

| 方法 | 路径 | 入参 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/lost-found` | `type`(lost/found)、`category`、`status`(open/resolved/expired)、`keyword`、`page`、`size`（默认 10，最大 50） | 分页列表 |
| GET | `/api/v1/lost-found/{id}` | — | 详情 |
| POST | `/api/v1/lost-found` | `{ type, title, category?, description?, location?, image_url?, contact?, publisher_name?, user_id? }` | 新建，`type` 和 `title` 必填 |
| PUT | `/api/v1/lost-found/{id}` | 同上字段 | 更新 |
| PATCH | `/api/v1/lost-found/{id}/status` | `{ status }`，只能是 `open / resolved / expired` | 改状态 |
| DELETE | `/api/v1/lost-found/{id}` | — | 删除 |

#### 个人中心页

- 展示 `/api/v1/auth/me` 的用户信息；退出登录只清本地 DataStore，不需要调后端。

## 2. 后端怎么跑起来

后端代码不在本仓库，在原项目的 `backend/` 目录（作者本机路径：`d:\Trae CN\project\whoisthe4th\backend`）。**你需要找后端同学要一份可运行的副本，或者让他部署到局域网。**

### 2.1 启动步骤

```bash
cd backend
npm install
cp .env.example .env      # Windows: copy .env.example .env
npm run dev               # tsx watch 热重载，默认监听 8000
```

- 技术栈：Node.js + TypeScript（ESM）+ Express 4。
- Node 版本建议 18 及以上。
- 启动成功的标志：控制台打印 `后端服务已启动: http://localhost:8000`。
- 自检：浏览器打开 `http://localhost:8000/health`，应返回 `{"status":"ok",...}`。

### 2.2 端口与地址

| 场景 | 客户端填写的后端地址 |
| --- | --- |
| Android 模拟器 | `http://10.0.2.2:8000` |
| 真机（同一局域网） | `http://<电脑局域网IP>:8000`，例如 `http://192.168.1.10:8000` |
| 电脑本机浏览器 / curl | `http://localhost:8000` |

> `10.0.2.2` 是 Android 模拟器访问**宿主机**的固定别名，`localhost` 在模拟器里指向模拟器自己，**一定不能用**。
> 真机联调时记得关掉电脑防火墙对 8000 端口的拦截。

### 2.3 需要哪些环境变量

最小可运行集合（复制 `.env.example` 后按需填）：

| 变量 | 作用 | 说明 |
| --- | --- | --- |
| `PORT` | 后端端口 | 默认 8000，改了客户端地址也要改 |
| `DASHSCOPE_API_KEY` | 大模型 Key | **AI 问答必填**，阿里云百炼 |
| `DASHSCOPE_MODEL` | 模型名 | 默认 `qwen-plus` |
| `ASR_PROVIDER` | 语音识别方式 | `mock`（默认，返回固定文本）/ `whisper-api` / `whisper-cli` |
| `TTS_PROVIDER` | 语音合成方式 | `edge`（默认，需要本机 Python + edge-tts）/ `mock` |
| `TTS_VOICE` | 音色 | 默认 `zh-CN-XiaoxiaoNeural` |
| `DB_*` | MySQL 连接 | 首页 / 景点 / 失物招领依赖 MySQL，默认端口 3307 |
| `JWT_SECRET` | token 签名 | 开发用默认值即可 |
| `REDIS_ENABLED` | Redis 开关 | 设为 `false` 可整体关闭，不影响启动 |
| `UPLOAD_MAX_BYTES` | 音频上传上限 | 默认 20MB |

要点：

- **不配 MySQL 也能启动**，但 `/api/v1/home`、`/api/v1/poi`、`/api/v1/lost-found` 会报 500；登录、问答、语音不依赖 MySQL。
- `ASR_PROVIDER=mock` 时无论上传什么音频都返回 `ASR_MOCK_TEXT`，适合先调 UI。
- `TTS_PROVIDER=mock` 会返回一段占位音频，也够调播放链路。
- 如果本机没装 Python，`edge` 音色合成会失败，先切 `mock`。

### 2.4 明文 HTTP 放行（必须做）

Android 9（API 28）起默认禁止明文 HTTP，直接请求 `http://10.0.2.2:8000` 会报 `CLEARTEXT communication not permitted`。需要在工程里加一份网络安全配置：

`app/src/main/res/xml/network_security_config.xml`

```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
    <!-- 仅调试环境放行明文 HTTP -->
    <domain-config cleartextTrafficPermitted="true">
        <domain includeSubdomains="true">10.0.2.2</domain>
        <domain includeSubdomains="true">localhost</domain>
        <!-- 真机联调时把电脑局域网 IP 也加进来 -->
    </domain-config>
</network-security-config>
```

`AndroidManifest.xml` 的 `<application>` 上引用：

```xml
<application
    android:networkSecurityConfig="@xml/network_security_config"
    ... >
```

> 只对开发环境放行，正式打包前记得收紧或改 HTTPS。

## 3. 硬约束与已知坑

### 3.1 后端侧（不要改，改了会连环崩）

1. **Express 必须是 4，不要升到 5。** Express 5 的 Response 行为会导致 SSE 的 `res.write()` 内容发不出去，问答和语音整条链路直接哑掉。
2. **音频上传字段名固定为 `audio`。** 后端是 `upload.single('audio')`，字段名写成 `file`、`audioFile` 都会返回 40002。
3. **TTS 是 GET + query，不是 POST body。** 文本放在 `?text=` 里，上限 **500 字符**，超了返回 40001。长文本要客户端自己切段。
4. **TTS 的 `audio` 事件给的是 Base64 字符串**，不是二进制流。必须 Base64 解码后按 `seq` 顺序追加写入临时文件，全部收完（`done`）再用 MediaPlayer 播放。
5. **SSE 必须自己解析。** 不要指望 Retrofit 的 Gson converter 或 `EventSource`：
   - `chat/stream` 是 **POST**，Android 没有内置 EventSource；
   - 用 OkHttp 发请求后拿 `response.body.source()` 逐行读，按空行（`\n\n`）分隔事件，解析 `event:` / `data:` / `id:` 三个字段；
   - 冒号开头的注释行是心跳，直接跳过；
   - OkHttp 的 `readTimeout` 必须设为 0（或很长），否则 25 秒没数据就被判超时断开；
   - 加 `Accept: text/event-stream` 请求头。
6. **`error` 事件后面还有一个空 `done`（`{}`）。** 解析 `done` 时不要直接取 `fullContent`，否则空指针崩溃。正确做法：以 `error` 为准，`done` 的字段做可空处理。
7. **`chat/stream` 的错误响应体是 `{ "error": "..." }`**，不是统一包络，和别的接口不一样。
8. **【已知限制】后端重启会丢登录账号。** 用户库是 SQLite，文件落在系统临时目录（`os.tmpdir()/whoisthe4th-auth.db`），后端进程重启或临时目录被清理后，之前注册的账号全部失效，登录会返回 401。
   - 这不是安卓端的 bug，**后端代码不改**（不在本项目范围内）。
   - 应对一：每次联调前先调 `POST /api/v1/auth/register` 注册新账号，再登录。
   - 应对二：**演示前统一注册一遍**，四个人共用同一批账号（账号密码发群里），不要到演示现场才注册。
   - 应对三：客户端把 401 处理成「回登录页 + 提示重新登录」，不要卡在加载态。

### 3.2 客户端侧（自己写代码时容易踩）

9. **模拟器用 `10.0.2.2`，真机用局域网 IP**，不要用 `localhost`。
10. **明文 HTTP 必须配 `network_security_config`**，见 2.4 节。
11. **录音权限要动态申请。** `RECORD_AUDIO` 属于危险权限，Android 6+ 必须运行时申请；只写 Manifest 不申请会直接抛异常。
12. **录音格式要和后端白名单对得上。** ASR 允许：`audio/wav`、`audio/x-wav`、`audio/wave`、`audio/mpeg`、`audio/mp3`、`audio/webm`、`audio/ogg`、`audio/mp4`、`audio/x-m4a`。推荐 `MediaRecorder` 录 AAC/MP4，或 `AudioRecord` 录 16k 单声道 PCM 再封 WAV。
13. **TTS 临时文件要清理。** 每轮播放新建一个临时文件，播放完或页面销毁时删掉；不要复用同一个文件边写边播（MediaPlayer 会读到半截文件）。
14. **失物招领的时间字段是数据库原始格式**，后端没做统一格式化，展示前自己解析。
15. **所有请求建议加统一日志拦截器**，把 `X-Trace-Id` 打出来，联调报错时直接甩给后端。

## 4. 项目范围与分工

### 4.1 一期范围（只做游客端 7 个页面）

1. **登录**（注册 / 登录 / 记住登录态）
2. **首页**（轮播、快捷入口、热门景点、推荐路线）
3. **景点列表**（分类筛选、跳详情）
4. **景点详情**（图文介绍、位置）
5. **AI 问答**（文字问答 + 语音输入 + 语音播报）
6. **失物招领**（列表筛选、发布、详情、改状态）
7. **个人中心**（用户信息、退出登录）

### 4.2 一期明确不做

- 管理后台（内容管理、用户管理、知识库上传、审计日志）
- 数字人形象 / 表情 / 口型驱动
- 路线个性化推荐算法（后端该接口还是规划态）
- 数据大屏、埋点统计看板
- 支付、地图导航全屏页

### 4.3 分工

| 成员 | 负责屏幕 | 负责技术块 | 对应分支 |
| --- | --- | --- | --- |
| **A** | 问答页的语音入口、个人中心 | 语音链路：录音 → ASR → TTS 流式接收 / Base64 解码落临时文件 → 播放；问答页语音交互整合 | `feature/a-voice` |
| **B** | 登录页、首页、AI 问答页（文字链路） | 网络基座：OkHttp/Retrofit、统一响应与错误模型、token 拦截器、SSE 解析器、页面状态管理 | `feature/b-network` |
| **C** | 景点列表页、景点详情页 | 列表与详情数据绑定、图片加载（Coil）、分类筛选、列表→详情跳转 | `feature/c-poi` |
| **D** | 失物招领三屏（列表 / 发布 / 详情） | 工程骨架（Gradle、包结构、导航、主题）、后端适配（BaseUrl 常量、`network_security_config`）、打包与答辩材料 | `feature/d-skeleton` |
